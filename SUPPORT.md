# Support

Use GitHub Issues for reproducible evaluator, schema, evidence, receipt, documentation or interoperability defects and bounded feature proposals. Include the affected method/revision, expected and observed behaviour, and the smallest useful evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).

DCAS owns evaluation method and decision-receipt semantics. Domain assurance requirements and upstream normative semantics remain with their owning repositories/authorities.
