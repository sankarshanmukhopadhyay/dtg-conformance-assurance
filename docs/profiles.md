# Conformance profiles

Profiles define *what is in scope* for a DCAS claim and what evidence/verifier expectations apply.

## Available profiles

- **CP-1 Issuer:** `conformance/profiles/CP-1_Issuer.md`
- **CP-2 Verifier:** `conformance/profiles/CP-2_Verifier.md`
- **CP-3 HolderAgent:** `conformance/profiles/CP-3_HolderAgent.md`
- **CP-4 NetworkManager:** `conformance/profiles/CP-4_NetworkManager.md`
- **CP-5 RegistryOperator:** `conformance/profiles/CP-5_RegistryOperator.md`
- **CP-6 GovernanceAuthority:** `conformance/profiles/CP-6_GovernanceAuthority.md`

## Adding a new profile
- Add the profile file under `conformance/profiles/`.
- Update `docs/profiles.md` and `docs/start-here.md` so adopters can discover it.
