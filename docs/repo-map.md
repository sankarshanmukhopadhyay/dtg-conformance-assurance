# Repository map

This repo is organized as an **end-to-end traceability spine**:

**Risks → Control Objectives → Controls → Evidence → Tests → Assurance output**

## Top-level folders

- `00_context/` — glossary, assumptions, and DTG working group scope
- `01_risk/` — risk register, exports, and traceability mappings
- `02_controls/` — control objectives + machine-readable catalogs (controls, evidence, tests)
- `03_conformance/` — assurance levels, conformance profiles, and claim examples
- `04_spec/` — DCAS specification text + annexes + schemas
- `05_governance/` — repo governance, review cycles, and release practices
- `docs/` — adoption guidance and the DCAS evaluation method
- `tools/` — lightweight scripts for exports and validation
