# Registry / trust list operator playbook

## Your job-to-be-done
Operate trust registries/lists as **critical infrastructure**: integrity, provenance, publication, dispute handling.

## Minimum adoption checklist (DCAS-aligned)
1. Publish signed registry content with provenance and cadence metadata (EV-005, EV-006).
2. Operate dispute/redress workflow for entries (EV-014).
3. Implement change control for registry updates (EV-003).
4. Maintain continuity objectives (EV-011 as operational evidence).

## Where this shows up in DCAS
- Conformance profile: `conformance/profiles/CP-RegistryOperator.md`
- Mandatory control objectives: CO2.1–CO2.3 (CO2.4 strongly recommended)
- Typical minimum AL: AL4

## Outputs you should be able to produce
- Registry publication bundle (signed data + metadata)
- Dispute and correction log excerpts
- Assurance report for registry controls
