# Auditor / assessor playbook

## Your job-to-be-done
Produce an assessment outcome that is **repeatable**, **explainable**, and **evidence-grounded**.

## Recommended workflow
1. Identify actor class + target assurance level (AL1–AL4).
2. Pull required COs from the conformance profile (`conformance/profiles/`).
3. Use `an implementer-supplied evidence artifact (e.g., audit report excerpt, test output, or signed attestation).` to enumerate required controls, evidence, and tests.
4. Execute tests (manual or automatable).
5. Produce an assurance report using `an implementer-supplied artifact appropriate to your context (e.g., risk register entry, test evidence, or approval record).`.

## Outputs you should be able to produce
- Evidence review notes mapped to controls
- Test results (per TS-###)
- Final assurance report + score/confidence rationale
