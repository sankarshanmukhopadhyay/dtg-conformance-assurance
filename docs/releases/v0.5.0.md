# v0.5.0

This release adds a concrete **A2A assurance overlay** to DCAS so agent ecosystems can evaluate more than bare protocol interoperability.

## Highlights

- Added **CP-7 A2A Agent / Service Endpoint** as a first-class conformance profile
- Added `docs/a2a-assurance-profile.md` to explain how DCAS should be applied to Agent Cards, task lifecycles, streaming, and webhooks
- Extended the control objective catalog with:
  - **CO3.5** Agent card integrity
  - **CO3.6** Task and context authorization scoping
  - **CO6.4** Streaming and webhook reliability
- Added an A2A example conformance claim for implementers and assessors
- Updated repo front-door docs so the A2A relationship is visible without spelunking through the repo like a digital cave goblin

## Notes

- DCAS remains transport- and protocol-neutral. This release adds an A2A-focused assurance overlay, not an A2A fork.
- For named agents, pair this release with ANAB v0.5.0.
