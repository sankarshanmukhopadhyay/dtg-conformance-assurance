# v0.1.1 — Adopter + developer readiness

This release turns the repo into an **issuer-first, CSV-first** adoption surface.

## Highlights

- Added a starter evidence bundle (CSV) under `templates/starter-bundle/`
- Added a canonical control objectives registry in CSV: `controls/control_objectives.csv`
- Introduced reproducible validation (`make validate`) and a CI workflow (`.github/workflows/validate.yml`)
- Fixed tooling path drift and made XLSX export optional (CSV remains the default)
- Rewrote onboarding docs to remove placeholders and dead ends (`README`, start-here, repo-map, FAQ)
- Removed maintainer-only broken reference inventory (replaced by automated checks)

## Upgrade notes

- If you previously referenced `01_risk/...` in local tooling, update to `risk/...`.
- Prefer the starter bundle structure for any new conformance/assurance submissions.
