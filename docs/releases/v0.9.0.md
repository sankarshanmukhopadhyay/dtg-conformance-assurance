# v0.9.0 — TSMM/TIS runtime assurance alignment

Released: 2026-06-29

## Release thesis

DCAS v0.9.0 makes runtime governance assurance evaluable. It aligns DCAS with TSMM as the semantic governance model and TIS v0.10.0 as the executable artifact contract layer for runtime assurance.

The release upgrades DCAS from evaluating individual runtime artifacts to evaluating the full runtime assurance chain: authority, delegation, scope, policy, evidence, revocation/status freshness, Trust Task execution evidence, integrity-bound evidence bundles, decision receipts, registry publication, and review path.

## Assurance impact

The release strengthens AL3 and AL4 interpretation for runtime assurance:

- AL3 evaluations should be independently replayable from authority, policy, evidence, status, and decision artifacts.
- AL4 evaluations should prefer integrity-bound evidence bundles, status/revocation checks, incident/change history, decision receipt retention, and periodic or continuous revalidation.

## Boundary rules

- TSMM owns runtime governance semantics.
- TIS owns machine-validatable artifact contracts.
- DCAS owns evidence sufficiency, assurance interpretation, evaluator workflow, and assurance outcome.

DCAS does not copy TIS schemas and does not redefine TSMM terms.
