# v0.7.0

This release adds an **experimental runtime-governance overlay** to DCAS.

## Highlights

- Added a portable runtime decision receipt pattern in `docs/patterns/runtime-decision-receipt.md`
- Added an experimental agent runtime controls overlay in `docs/experimental/agent-runtime-controls.md`
- Added `conformance/examples/runtime_decision_receipt.example.yaml` as a verifier-facing example artifact
- Extended the control, evidence, and test registries with runtime admission, decision traceability, and fail-safe behavior expectations

## Notes

- DCAS remains an assurance packaging and evaluation method. This release does **not** turn the repository into a runtime middleware implementation.
- The Microsoft Agent Governance Toolkit is used as an upstream conceptual reference for runtime interception and audit-trace thinking, not as a normative dependency.
