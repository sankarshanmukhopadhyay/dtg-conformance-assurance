# DCAS v0.8.0 release notes

## Release title

DCAS v0.8.0 — TIS v0.9 Runtime Trust Artifact Evaluation Alignment

## Summary

This release aligns DCAS with `trust-infrastructure-schemas` v0.9.0 and its DTG/OpenVTC/VTI runtime trust artifact compatibility profiles. The release makes DCAS an explicit evaluator of TIS-backed runtime evidence without copying TIS schemas or changing the stable DCAS control namespace.

## What changed

- Added a TIS v0.9 runtime artifact evaluation profile.
- Added a TIS drift review process and machine-readable compatibility review manifest.
- Added a worked evaluation claim for DTG/OpenVTC/VTI runtime artifacts.
- Added a TIS/DCAS/ANAB alignment matrix and known-good stack statement.
- Refreshed README, docs index, interoperability docs, compatibility matrix, roadmap, and changelog.
- Extended validation to parse the new TIS evaluation example and verify the compatibility manifest.

## Why it matters

TIS v0.9.0 adds concrete runtime trust artifact profiles for credential envelopes, OpenVTC relationship and issuance state, VTI authorization and provision evidence, decision receipts, and evidence manifests. DCAS now gives evaluators a repeatable way to ask whether those artifacts are sufficient for assurance decisions.

## Compatibility

This is an additive release. Existing DCAS examples, controls, and CSV contracts remain valid.

## Validation

```bash
make validate

```
