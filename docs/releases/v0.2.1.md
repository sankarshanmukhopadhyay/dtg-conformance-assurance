# DCAS v0.2.1 (2026-03-05)

## What changed

- Added CI workflows for deterministic validation and coverage generation.
- Added internal-only link checking on PRs, with a separate scheduled external link audit.
- Removed stale OS artifacts (e.g., `.DS_Store`).
- Added `VERSION` file (kept `DCAS_METHOD_VERSION` as the authoritative method version marker).

## Compatibility

- No intended breaking changes relative to v0.2.0.
- Downstream repos SHOULD update their pinned DCAS method reference from **v0.2.0 → v0.2.1**.
