# v0.2.0 — Automated coverage + CSV schema descriptors + verifier workflow

This release hardens DCAS as an **operational, automatable** adoption surface.

## Highlights

- **Coverage report generator (CSV + Markdown):** `tools/coverage_report.py` and `make coverage`
- **Machine-readable CSV schema descriptors:** `schemas/csv/` (drives `make validate`)
- **Verifier-first workflow:** `docs/verifier-workflow.md` (intake → validation → coverage → decision)

## Automation posture

Most checks are now automatable and enforced in CI:

- CSV required columns + light type/enum checks
- Referential integrity for control objective IDs
- Deterministic coverage output regeneration checks
- Markdown relative link integrity

## Upgrade notes

- Prefer the CSV schema descriptors under `schemas/csv/` as the “contract” for bundle structure.
- Coverage reports are deterministic (CI regenerates and asserts no diff).
