# v0.1.0 — DCAS baseline (issuer-first)

This release establishes a **CSV-first adoption surface** for DTG Conformance & Assurance (DCAS).

## What’s included

- Starter evidence bundle templates: `templates/starter-bundle/`
- Control objectives registry (CSV): `controls/control_objectives.csv`
- Repo validation tooling + CI: `tools/validate.py` and `.github/workflows/validate.yml`
- Updated “front door” docs: `README.md`, `docs/start-here.md`, `docs/repo-map.md`, `docs/FAQ.md`

## What changed vs earlier drafts

- Removed maintainer-only broken reference inventory (replaced by automated checks)
- Replaced placeholder “artifact not included” language with in-repo templates and concrete workflows
- Fixed tooling paths and made validation reproducible (`make validate`)
