# DCAS v0.10.0 Release Notes

## Release Title

DCAS v0.10.0 - AIS-1 v0.2 Experimental Evaluation Profile

## Summary

DCAS v0.10.0 upgrades the experimental AIS-1 evaluator lane for AIS-1 v0.2. The release gives assessors a practical way to evaluate bonded agent identity and accountability evidence without overstating what AIS-1 proves.

AIS-1 v0.2 introduces useful new evidence surfaces: ALA/SOA classification, `parentDid`, DID resolution, registry status, timestamp service references, Assurance Container references, and SOA cascade revocation behavior. DCAS now turns those surfaces into testable evaluator expectations.

## What Changed

- Expanded CP-8 into an AIS-1 v0.2 experimental evaluator profile.
- Added evaluator checks for:
  - ALA/SOA classification;
  - SOA parent DID and parent ALA status;
  - DID resolution;
  - registry status;
  - bond integrity;
  - timestamp service references;
  - Assurance Container references;
  - SOA cascade revocation and negative-path behavior.
- Added new control objectives:
  - `CO3.9` AIS-1 SOA parent-chain validation;
  - `CO4.8` AIS-1 v0.2 evidence sufficiency;
  - `CO6.6` AIS-1 cascade revocation handling.
- Added AIS-1 v0.2 evidence catalog entries, test suite entries, starter-bundle mappings, and risk mappings.
- Added a refreshed worked evaluation claim for an AIS-1 v0.2 SOA.
- Added portfolio drift review and release impact documentation.
- Updated validation tooling to check the AIS-1 v0.2 claim.

## Why It Matters

Agent ecosystems need a way to distinguish identity from authority. AIS-1 v0.2 can help identify an agent, expose who stands behind it, and reveal whether a subordinate agent is tied to an active parent. That is valuable evidence, but it is not enough to authorize consequential action.

DCAS v0.10.0 makes this distinction operational. Evaluators can now test whether AIS-1 v0.2 evidence is coherent, fresh, traceable, and safe to rely on as an accountability input while still requiring separate evidence for delegated authority, runtime authorization, and provenance.

## Compatibility

This is an additive release. Existing DCAS profiles and examples remain valid.

The method version is updated to `0.5.0` because the evaluator catalog now includes explicit AIS-1 v0.2 evidence and test expectations.

## Validation

Run:

```bash
make validate
make coverage
```

Expected result: all checks pass.

## Release Boundary

DCAS v0.10.0 does not treat AIS-1 as a settled production trust profile. It remains experimental. The release provides evaluator discipline for using AIS-1 v0.2 as identity and accountability evidence while preserving the separation between identity, delegation, authority, provenance, and assurance.
