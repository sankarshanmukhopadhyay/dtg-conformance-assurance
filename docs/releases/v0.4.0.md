# v0.4.0

This release introduces **transport alignment** guidance with the ToIP **Trust Spanning Protocol (TSP)** and strengthens CI hygiene for predictable assurance operations.

## Highlights

- Added transport alignment documentation for TSP, clarifying how DCAS operates in deployments that exchange artifacts over a secure transport.
- Updated architecture snapshot to include the transport layer and fixed Mermaid syntax for GitHub rendering.
- Added Dependabot configuration for GitHub Actions and Python dependency updates.
- Hardened GitHub Actions workflows (concurrency, permissions, caching) and added Mermaid parsing checks to prevent doc regressions.

## Notes

- DCAS remains transport-agnostic; TSP is referenced as a candidate transport substrate.
