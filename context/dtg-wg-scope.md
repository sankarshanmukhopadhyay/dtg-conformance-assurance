# DTG Working Group scope (orientation)

This repo is intended to support DTG Working Group-aligned implementations by providing:
- A **common structure** for conformance and assurance claims
- **Machine-readable schemas** to enable automated validation
- Guidance for implementers, auditors, and tooling builders

## In scope
- Claim schemas (conformance + assurance)
- Example claim payloads and validation guidance
- Mapping notes to controls/risk profiles used in DTG artifacts

## Out of scope
- Operating a production registry or trust list
- Defining sector-specific regulatory obligations
- Replacing an organization’s internal governance program

## Relationship to other DTG repositories
Where DTG ecosystem repositories share vocabulary (e.g., Assurance Levels), this repo aims to remain aligned to the canonical definitions to avoid interpretive drift.
